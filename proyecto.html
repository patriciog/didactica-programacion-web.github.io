1. Elaboración del Proyecto

El objetivo es crear una página web interactiva,, de temática libre, visualmente atractiva y funcional que demuestre tus habilidades como desarrollador Frontend Junior. Deberás aplicar todo lo aprendido sobre estructura (HTML5), diseño (CSS3) y dinamismo (JavaScript).

2. Requisitos Técnicos

Estructura HTML5

La página debe estar bien organizada semánticamente. Es obligatorio incluir:

  • header: Con un título principal y un menú de navegación.
  • nav: Con al menos 3 enlaces internos (anclas) o externos.
  • section y article: Para organizar el contenido principal.
  • aside: Una barra lateral con información secundaria o curiosidades.
  • Multimedia: Al menos una imagen optimizada y un video (enlazado o local).
  • footer: Con información de contacto y derechos de autor.

Estilos CSS3

Queremos que la web entre por los ojos. Se evaluará:

  • Modelo de caja: Uso correcto de margins, paddings y borders.
  • Layout: Uso de Flexbox o Grid para posicionar los elementos.
  • Tipografía: Uso de Google Fonts y jerarquía de tamaños.
  • Efectos: Al menos un efecto hover en los botones o enlaces y una transición suave.
  • Responsive Design: La web debe verse bien tanto en ordenador como en móvil (uso de @media queries).
  • El código CSS tiene que estar independiente del resto de código.

Código JavaScript

La página no puede ser estática. Debes implementar:

  • Menú dinámico: Un script para visualizar un menú desplegable.
  • Validación de formulario: Un pequeño formulario de "Contacto" que avise al usuario mediante un alert o un mensaje en el DOM si falta algún campo por rellenar.
  • Elemento interactivo: Un botón que, al ser pulsado, cambie algo en la página (el color de fondo, oculte/muestre una sección o cambie el tamaño de una imagen).
  • El código JavaScript tiene que estar independiente del resto de código.
