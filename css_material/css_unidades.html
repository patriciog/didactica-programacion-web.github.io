Unidadses en CSS

Las unidades en CSS se utilizan para definir tamaños, espacios y proporciones.

Unidad Tipo Descripción Ejemplo
px Absoluta Tamaño fijo en píxeles font-size: 16px;
% Relativa Depende del tamaño del elemento padre width: 50%;
em Relativa Relativa al tamaño de fuente del padre font-size: 1.5em;
rem Relativa Relativa al tamaño de fuente raíz (html) font-size: 1rem;

En general es recomendable usar medidas relativas en el tamaño del texto (font-size). Esto permite adaptar la página a diferentes dispositivos y resoluciones.
