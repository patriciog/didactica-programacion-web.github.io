Box Model

El modelo de caja (Box Model) es la base del diseño en CSS. Cada elemento HTML se representa como una caja rectangular compuesta por varias capas.

Capa Descripción Función Ejemplo CSS
Content Contenido del elemento (texto, imagen, etc.) Es la parte principal donde se muestra la información width: 200px;
Padding Espacio interno entre el contenido y el borde Añade “aire” dentro del elemento padding: 20px;
Border Borde que rodea el padding y el contenido Define el contorno visual del elemento border: 2px solid black;
Margin Espacio externo alrededor del elemento Separa el elemento de otros elementos margin: 10px;

En CSS existen diferentes formas de asignar valores a las propiedades margin y padding, lo que permite ajustar el espacio alrededor y dentro de los elementos de manera flexible. Estas formas pueden ser abreviadas o detalladas, dependiendo del nivel de control que se necesite.

Forma Ejemplo CSS Descripción
Valor único margin: 10px;
padding: 10px;		 Se aplica el mismo valor a los 4 lados
2 valores margin: 10px 20px;
padding: 10px 20px;		 1º valor: top/bottom
2º valor: right/left
3 valores margin: 10px 20px 30px;
padding: 10px 20px 30px;		 1º top, 2º right/left, 3º bottom
4 valores margin: 10px 20px 30px 40px;
padding: 10px 20px 30px 40px;		 Orden: top, right, bottom, left
Forma detallada margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px; 		Control individual de cada lado
