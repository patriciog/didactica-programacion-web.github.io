Colores en CSS

Existen varias formas de especificar el valor de la propiedad color (color del contenido del elemento) o background-color (color del fondo del elemento) en CSS.

Método Ejemplo CSS Resultado
Nombre color: red; Texto rojo
HEX (Hexadecimal) color: #ff0000; Texto rojo
RGB color: rgb(255, 0, 0); Texto rojo
RGBA color: rgba(255, 0, 0, 0.5); Texto rojo transparente
