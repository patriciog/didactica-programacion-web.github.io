Sintaxis de CSS

La sintaxis de CSS es muy sencilla y se basa en reglas. Cada regla tiene tres partes principales:

  • Selector: Indica el elemento HTML que quieres modificar (por ejemplo: p, h1, ul).

  • Propiedad: El aspecto que quieres cambiar (por ejemplo: color, font-size, background).

  • Valor: El ajuste específico que aplicas (por ejemplo: red, 20px, blue).
