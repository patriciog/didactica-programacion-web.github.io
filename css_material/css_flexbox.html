Flexbox

Flexbox es un sistema de diseño en CSS diseñado para organizar y distribuir elementos dentro de un contenedor de forma eficiente.

Una buena forma de practicarlo es utilizando la página Flexbox Froggy, un juego interactivo donde debes resolver niveles aplicando propiedades de Flexbox para colocar las ranas en sus posiciones correctas.
