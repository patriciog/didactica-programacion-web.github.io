Operadores y expresiones

La sintaxis incluye una amplia gama de operadores para manipular estos datos:

Aritméticos y Asignación: Soportan las operaciones matemáticas clásicas (+, -, *, /, módulo % y potencia **), incrementos/decrementos (++, --) y formas abreviadas de asignación como += o *=. El operador + también se utiliza para concatenar (unir) cadenas de texto.

let suma = 5 + 3; // 8 let diferencia = 10 - 4; // 6 let resto = 10 % 3; // El resultado es 1 (porque 3 entra 3 veces en 10 y sobra 1) let alCuadrado = 5 ** 2; // 25 (5 elevado a la potencia de 2)

Comparación: JS ofrece comparaciones débiles (==, !=) y comparaciones estrictas (===, !==). Las estrictas son especialmente importantes porque verifican no solo que el valor sea igual, sino que el tipo de dato también coincida.

Operación Operador Ejemplo Resultado
Igualdad == 10 == "10" true (solo mira el valor)
Igualdad Estricta === 10 === "10" false (mira valor y tipo de dato)
Diferente != 5 != 3 true
Diferente Estricto !== 5 !== "5" true

Lógicos: Permiten encadenar condiciones usando && (AND), || (OR) y negar expresiones con ! (NOT).
